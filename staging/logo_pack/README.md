# Snapflow Logo Pack

Local copies of the marks used by the Snapflow landing page.

| File | Source | Usage |
|---|---|---|
| `snapflow.svg` | Local Snapflow favicon asset | Site mark and favicon |
| `openai.png` | `https://github.com/openai.png?size=256` | OpenAI provider card |
| `anthropic.png` | `https://github.com/anthropics.png?size=256` | Anthropic provider card |
| `agent-skills.ico` | `https://agentskills.io/favicon.ico` | Agent Skills provider/format card |
| `mcp.svg` | `https://raw.githubusercontent.com/modelcontextprotocol/go-sdk/main/docs/images/logo-light.svg` | Model Context Protocol section mark |
| `build-linux.svg` | Snapflow GitHub Actions badge | Linux build status |
| `build-macos.svg` | Snapflow GitHub Actions badge | macOS build status |
| `build-windows.svg` | Snapflow GitHub Actions badge | Windows build status |

The site consumes static copies from `codebases/prv/snapflow_site-worktree/public/brand/`.
The Agent Skills mark supplies the warm orange accent used by the site theme.
